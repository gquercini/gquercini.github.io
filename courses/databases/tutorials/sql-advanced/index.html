Advanced SQL

In this tutorial we’ll learn two important advanced SQL features: common table expressions (CTE) and window functions. For this part, we’ll use the sales transaction database that we used in the previous SQL tutorial.

A Common Table Expression (CTE) allow you to define a temporary table from the result of a subquery that can be used inside anothe query. This tool has been defined in the SQL:1999 standard. A CTE is very useful when you want to break a complex query into smaller building blocks that can then be composed together.

The following query returns all the sale transactions that are involved in at least one sale (Vente) transaction or in at least one exchange (Echange) transaction but not in both.

The query first uses the keyword WITH to define sale_and_exchange as a table obtained from a SQL query defined after the keyword AS; then, sale_and_exchange is used in the subsequent query.

WITH sale_and_exchange  AS (
    SELECT DISTINCT property_id
    FROM sales_transaction
    WHERE transaction_type = 'Vente'
    INTERSECT 
    SELECT DISTINCT property_id
    FROM sales_transaction
    WHERE transaction_type = 'Echange'
)
SELECT DISTINCT property_id
FROM sales_transaction
WHERE transaction_type IN ('Vente', 'Echange')
EXCEPT
SELECT DISTINCT property_id
FROM sale_and_exchange

It is also possible to define two temporary tables. The following example defines

  • a temporary table sale that contains all properties involved in at least one sale transaction.

  • a temporary table exchange that contains all properties involed in at least one exchange transaction.

In this case, the keyword WITH is only written once, as shown in the following example

WITH sale  AS (
    SELECT DISTINCT property_id
    FROM sales_transaction
    WHERE transaction_type = 'Vente'
),
exchange AS (
    SELECT DISTINCT property_id
    FROM sales_transaction
    WHERE transaction_type = 'Echange'
)
SELECT DISTINCT property_id
FROM sales_transaction
WHERE transaction_type IN ('Vente', 'Echange')
EXCEPT (
SELECT DISTINCT property_id
FROM sale
INTERSECT
SELECT DISTINCT property_id
FROM exchange
)

Let’s try some exercises using a CTE.

Exercise

Exercise 1 Find the 10 cities that have the most of the transactions in December 2025. To write this query write a CTE:

  • one CTE to obtain a table that contains the sales transactions in December 2025.

  • Count the number of transactions per city on that table.

Solution 
WITH last_two_months AS (
    SELECT transaction_id, property_id
    FROM sales_transaction
    WHERE transaction_date >= date('2026-01-01') - 31
)
SELECT city_id, city_name, COUNT(*) AS nb_transactions
FROM city JOIN street USING (city_id)
          JOIN property USING (street_id)
          JOIN last_two_months USING(property_id)
GROUP BY city_id, city_name
ORDER BY nb_transactions DESC 
LIMIT 10

Exercise

Exercise 2 Write a SQL query that counts per each region the number of transactions whose property value is above the regional average property value. To write this query use two CTEs.

  • One CTE to obtain a table that includes per each transaction, the identifier of the transaction, the property value, the region code and the region name.

  • One CTE to obtain a table that includes the average property value per region.

  • Use the two CTEs to count in each region the number of transactions whose value is above the regional property value.

Solution 
WITH transaction_value_in_region AS (
    SELECT reg_code, reg_name, transaction_id, property_value
    FROM sales_transaction 
        JOIN property USING (property_id)
        JOIN street USING (street_id)
        JOIN city USING (city_id)
        JOIN department USING (dept_code)
        JOIN region USING (reg_code)
),
avg_value_by_region AS (
    SELECT reg_code, AVG(property_value) AS avg_prop_value
    FROM transaction_value_in_region
    GROUP BY reg_code
)
SELECT reg_code, reg_name, COUNT(transaction_id) AS nb_transactions
FROM transaction_value_in_region JOIN avg_value_by_region USING(reg_code) 
WHERE property_value > avg_prop_value
GROUP BY reg_code, reg_name

Exercise

Exercise 3 Write a SQL query that returns or each department, the number of main rooms that occurs most frequently among its properties, along with the number of properties having that number of rooms.

Use two CTEs.

  • The first CTE counts the number of properties for each combination of department code, department name, and number of main rooms.

  • The second CTE finds the maximum number of properties for each department.

Solution 
WITH room_counts AS (
    SELECT
        dept_code,
        dept_name,
        num_main_rooms,
        COUNT(DISTINCT property_id) AS nb_properties
    FROM property
    JOIN street USING (street_id)
    JOIN city USING (city_id)
    JOIN department USING (dept_code)
    GROUP BY dept_code, dept_name, num_main_rooms
),
max_counts AS (
    SELECT
        dept_code,
        MAX(nb_properties) AS max_properties
    FROM room_counts
    GROUP BY dept_code
)
SELECT
    dept_code,
    dept_name,
    num_main_rooms,
    nb_properties
FROM room_counts
JOIN max_counts USING (dept_code)
WHERE nb_properties = max_properties;

Exercise

Exercise 4 Modify the previous query so that the number of main rooms is displayed as categories: “2 rooms”, “3 rooms”, “4 rooms”, and “5 rooms or more”, while preserving the corresponding property count for each category.

Solution 
WITH room_counts AS (
    SELECT
        dept_code,
        dept_name,
        num_main_rooms,
        COUNT(DISTINCT property_id) AS nb_properties
    FROM property
    JOIN street USING (street_id)
    JOIN city USING (city_id)
    JOIN department USING (dept_code)
    GROUP BY dept_code, dept_name, num_main_rooms
),
max_counts AS (
    SELECT
        dept_code,
        MAX(nb_properties) AS max_properties
    FROM room_counts
    GROUP BY dept_code
)
SELECT
    dept_code,
    dept_name,
    CASE 
        WHEN num_main_rooms = 2 THEN '2 rooms'
        WHEN num_main_rooms = 3 THEN '3 rooms'
        WHEN num_main_rooms = 4 THEN '4 rooms'
        ELSE '5 rooms or more'
    END AS nb_main_rooms,
    nb_properties
FROM room_counts
JOIN max_counts USING (dept_code)
WHERE nb_properties = max_properties;
